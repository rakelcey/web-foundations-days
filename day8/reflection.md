# Course Reflection

Throughout this web foundations and system design course, I have had continuous moments of learning and challenging myself.

The most interesting lesson for me was the databases and the system design, as it related with my interests. The most difficult concept for me to master was understanding JavaScript, especially the DOM, but the notes in the PLP and the class sessions were very informative and in simple, easy to grasp language which made it easier for me to grasp the content and now I feel confident in my JavaScript skills gained so far. 

I also had a challenge with concurrency—specifically preventing race conditions like double-booking when thousands of users write to the database at the exact same time, but by breaking down ACID properties, I was able to understand how to go about it and what to always consider.

I have learnt the true need for consistency, especially with Git, and it has been exciting learning how much I am able to accomplish with just a few commands, to save time and also make work easier. This is something that I look forward to practicing more and more for best efficiency.

The primary area I need to improve is my error handling and input validation on both the frontend and backend; this will ensure a much more resilient user experience.
