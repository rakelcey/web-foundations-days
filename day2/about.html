About QuickNotes

QuickNotes is a lightweight web application designed to help you capture ideas and manage your daily tasks seamlessly. It provides a simple, clutter-free experience so you can stay focused on writing down what matters most.

How to use QuickNotes

  1. Type your task or idea into the input field on the home page.
  2. Click the "Add Note" button to save it to your list.
  3. Review your active notes anytime from your dashboard.

Features

  • Fast and lightweight user interface
  • Instant note creation
  • Simple keyboard shortcut support

Keyboard shortcuts

Shortcut Action
Ctrl + N Create a new note
Ctrl + S Save current note
